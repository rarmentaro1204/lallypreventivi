# Lally Preventivi

Gestionale per Lally Decò (allestimenti floreali per eventi e matrimoni).
Pagina statica unica (`index.html`), nessuna build: si apre nel browser o si pubblica su Netlify.

Tre schede: **Preventivi**, **Eventi confermati**, **Preventivatore** (wizard a 4 step).
Ogni preventivo/evento ha dati, allestimenti, extra, economics (rate, incassi, costi, margine) e documento stampabile.
I dati sono salvati nel browser; "Esporta dati / Importa dati" per le copie di backup.
